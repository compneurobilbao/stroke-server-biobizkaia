# Documentation

- English, Markdown, Mermaid where a diagram helps. Short, verifiable, technical; document the real state of the code.
- Normative documents: the plan (`docs/plan/`), the step contract (`docs/contracts/`) and the ADRs (`docs/adr/`, accepted records are superseded, never edited); they change only through their card and with owner approval.
- Update the docs affected by a change in the same PR, within the card's "Touches" list. `make check-docs` lists the required documents.
- Public repository: no people's names, no server, host or institution details, no grant references; the modelling partner is "SP2".
