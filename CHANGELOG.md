# Changelog

All versions follow semantic versioning and Conventional Commits.

## Unreleased

- SLNM-01: new step `slnm-coarse` 1.0.0 (contract 1.2, in development): wrapper of the `slnm-coarse` command of the author's fast-slnm repository, installed unmodified at `226f2ece` (MIT; `upstream.env` pins the content), with ANTs `antsApplyTransforms` 2.6.3 (checksum-pinned) as in the author's image. Per lesion it warps the lesion to each normative participant's diffusion space with the portable cohort cache and writes the site-balanced parcel-level structural disconnection map on the working grid with NaN (never zero) for parcels without a valid estimate, plus the validity mask; warnings `unsupported_parcels`, `lesion_lost_in_native_space`, `lesion_outside_native_atlas`; parameter `workers` (default 2, capped at the granted CPUs). Artefact type registry 1.1.0 (minor, additive): `sdisconnection_map`, `sdisconnection_valid_mask`. New bundle type `slnm-coarse-cache` (free kebab-case bundle type; no contract change) with a builder from the author's `coarse_files` cache (`steps/slnm-coarse/bundle/build_bundle.py`); the real bundle is HCP Aging derived, server-only, not redistributable, not built yet. Synthetic reference case and tests; CI job `slnm-coarse-container`, which skips the image build and reference tests with a warning while the author's repository is private and not readable by the workflow token. `steps/fetch-upstream.sh` reads a private repository with `UPSTREAM_TOKEN`/`GITHUB_TOKEN` and exits 3 when it is not readable. `stroke-lnm` lists the stage as in development (`in_development` entry `slnm-coarse`, en/es); `pipeline.yaml`, the pipeline version, the profiles and the presets are unchanged.

- REPORT-02: `research-report` 0.5.0 (report 1.3) states on the first page, and in the notes, "Example input: synthetic lesion, not patient data" when a run input carries the reserved origin `stroke-server-example` of the platform's synthetic example inputs (read from the run record of contract 1.2; no contract change; new note `synthetic_example_input`). `stroke-lnm` 0.11.0 pins it (digest pending release, `published: false`), presets 1.9.0.
- COMPOSE-01: Docker Compose forwards `PRESETS_DIR` (empty default, so behaviour is unchanged when unset) to `api` and to `seed-implementations`.

- STEPS-02 / TRACTS-01: `lnm-tracts` 1.1.0 resamples the lesion (MNI152NLin6Asym) into the space of the tract atlas by nearest neighbour when the atlas bundle declares another space (`metadata.space`), with the transform of the new optional bundle `space_transform` (type `space-transform`, a coordinate map); voxel counts and volumes before and after are recorded (warning `lesion_resampled_to_atlas_space`, `extra/atlas_space_resampling.json`); new codes `space_transform_missing`, `space_transform_mismatch` (internal) and `mask_outside_atlas_space` (input rejected). Atlases without `metadata.space` give the tables of 1.0.1 (CI compares with the published 1.0.1 image); tests use synthetic spaces only (identity and 4 mm shift). `scripts/bundles/space_transform` builds `xfm-nlin6asym-to-nlin2009aasym` 1.0.0 from the TemplateFlow transform (pinned sources and checksums, MNI ICBM 2009 licence; open points in docs/reference-data.md). `stroke-lnm` 0.10.0 pins `lnm-tracts` 1.1.0 (digest pending release, `published: false`) and, for the lab's HCP1065 entry, `hcp1065-tracts` 1.1.0 (declares MNI152NLin2009aAsym) with that transform; presets 1.8.0.

- STEPS-01: the step wrappers of the lab's tools live in this repository (`steps/cognet-stroke`, `steps/lnm-tracts`, `steps/ct-lesion-to-mni152`) and consume the authors' repositories unmodified at pinned commits (`upstream.env`, registry `source.upstream`, checked by `registry.py check`; `registry.py fetch` fetches them). `cognet-stroke` 1.1.0 (contract 1.2) calls the author's `compute_cdr` and `compute_overlap` (COGNET-STROKE `64678b11`, MIT; the code of `f98dbc8`, `nanmean`), accepts NaN in the functional map and writes `excluded_parcels`, rejects infinite values and maps without a defined value in any parcel (`disconnection_map_undefined`), reads the parcellation from the bundle, and ships a slim image (numpy, nibabel, matplotlib); a bundle builder makes the `concept-maps` bundle from the author's workflow outputs and null cache. `lnm-tracts` 1.0.1 and `ct-lesion-to-mni152` 1.0.1 are the 1.0.0 code rebuilt from here (CI compares them with the published 1.0.0 images). `stroke-lnm` 0.9.0 pins them (digests pending release, `published: false`), presets 1.7.0; `research-report` 0.4.0 is pinned to its published digest. Review fixes: `upstream.env` pins the content of the files taken from the author's repository (`UPSTREAM_SHA256`, checked in the Dockerfiles and by `steps/fetch-upstream.sh`); cognet-stroke reports a degenerate null distribution (no spread, e.g. a map without positive values) with a null p-value instead of the 1/n_nulls that made 1.0.0 call such scores significant, and warns about null maps without a defined value, tied null values and partly defined parcels (`degenerate_null_distribution`, `undefined_null_maps`, `tied_null_values`, `parcels_partly_defined`); COGNET-STROKE is MIT since `64678b11` (licence added by the repository owner), which the wrapper pins and records in `licence_review`.

- COGNET-02: parcels without a value (NaN) in the functional disconnection map no longer stop a real run. `cognet-profile` schema gains the optional `excluded_parcels` `{count, fraction, reason}`; `research-report` 0.4.0 (report 1.2) accepts NaN voxels in the functional map and states in the COGNET section how many parcels were excluded, when the profile says so; `stroke-lnm` 0.8.0 pins it (digest pending release, `published: false`), presets 1.6.0.

- MVP-01: the lab `deployment` profile is the minimum pipeline (lesion mask in MNI152 -> flnm-fast and COGNET, lnm-tracts -> report); `stroke-lnm` 0.7.0 with the published step digests and bundle-pinned entries for the lab's tract atlas and concept maps; preset `mni-mask-analysis` 1.5.0 requires COGNET. Stages that cannot be used yet (normalisation, lesion segmentation, lesion bank, voxel-wise structural LNM) are listed by the API and shown greyed and labelled "In development" in the wizard and on the run page. Implementation display titles per cohort (en, es). Synthetic example inputs are shown as provided by the platform.
