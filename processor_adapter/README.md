# Processor Adapter

This folder contains the mandatory boundary between the web platform and the external neuroimaging processing script.

## Responsibility

- Treat the external script as an isolated component.
- Receive input and output paths, logs path and study identifier.
- Select the backend through `PROCESSOR_BACKEND`.
- Build the CLI command from `PROCESSOR_COMMAND` in `dummy` mode or `COMPNEURO_COMMAND` in `compneuro` mode.
- Run the command and capture `stdout`/`stderr`.
- Store technical logs.
- Detect the results produced by the configured backend.
- Render NIfTI to PNG and generate technical artefacts when the worker asks for it.
- Return a structured result to the worker.

## Code Layout

- `adapter.py`: defines `ProcessorAdapter` and `ProcessorResult`.
- `nifti_renderer.py`: finds `.nii`/`.nii.gz` in `Preproc` and runs FSL `slicer`.
- `technical_pdf_report.py`: generates the technical PDF with metadata and PNG images.
- `output_packager.py`: generates the results ZIP with relative paths.
- `artifacts.py`: keeps compatibility with previous imports.
- `__init__.py`: exports the package's public classes.

## `ProcessorResult`

The result contains:

- `success`: whether the backend run was successful.
- `exit_code`: exit code of the external process.
- `pdf_path`: path of the first PDF detected or of the technical PDF generated by the platform.
- `log_path`: path of the generated log file.
- `error_message`: controlled message for diagnostics.
- `duration_seconds`: total duration.
- `output_files`: detected results.
- `output_zip_path`: ZIP generated by the platform, if applicable.
- `preproc_path`: `output/Preproc` path in `compneuro` mode.
- `warnings`: non-blocking technical warnings.

## Security And Coupling

The adapter checks that the input directory exists and creates the output/logs directories if missing. It does not interpret medical content or modify the external processor.

Example command:

```env
PROCESSOR_COMMAND=python /app/external_processor/dummy_processor.py --input {input_dir} --output {output_dir} --study-id {study_id}
```

For `compneuro`, the default command is:

```env
COMPNEURO_COMMAND=bash /app/src/apreproc_launcher.sh
```
