# Example inputs

Synthetic example files the API can offer when `EXAMPLE_INPUTS_DIR` points here
(off by default; see `docs/configuration.md`). `manifest.json` lists them. The mask files
are copied from `fixtures/data/mni_masks/` by `backend/Dockerfile` at image build time
(synthetic, CC0-1.0, generated by `python -m fixtures.generate`); they are not committed
a second time.
