# Data

This folder is the local mount point for data generated by the application.

## Responsibility

- Store uploaded studies.
- Store the BIDS structure prepared per study.
- Store processor results, the technical PDF and the ZIP.
- Store the processor's technical logs.
- Keep local metadata per study.

## Expected Layout

```text
data/
  studies/
    {study_id}/
      input/original/
      bids_project/data/sub-XXXX/anat/
      runtime_project/
      output/
        Preproc/
        rendered_png/
        reports/technical_report.pdf
        outputs.zip
      logs/
      metadata.json
```

## What Is Versioned

Only `.gitkeep` and this `README.md` are versioned. Real studies, results and logs are ignored by Git.

## Warning

Do not store identifying data. The current version assumes anonymised studies and applies the initial retention through CLI/configuration, not from the GUI; real deletion is disabled by default.
